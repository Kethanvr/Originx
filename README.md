# OriginX Heritage Hub

OriginX is a React interface prototype for discovering products by region and browsing a sample storefront inspired by India's regional crafts and goods.

The app includes routes for product browsing and search, product details, a cart and order screens, regional discovery, seller onboarding, and help pages. Product and seller examples are defined in the frontend. This repository does not include a commerce backend or payment integration, so treat these screens and policies as prototype content rather than live store operations.

## Built with

- React 18 and TypeScript
- Vite and React Router
- TanStack Query
- Tailwind CSS, Radix UI, and related component utilities

## Run locally

    npm install
    npm run dev

Vite prints the local URL when the server starts.

## Available scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production bundle.
- `npm run build:dev` builds with Vite's development mode.
- `npm run lint` runs ESLint.
- `npm run preview` serves a built bundle locally.
